# Zählerwerk – Website

Support, Datenschutz, Impressum und Nutzungsbedingungen der App Zählerwerk, veröffentlicht über GitHub Pages.

Die Seiten werden im App-Repository mit `npm run site` aus den Rechtstexten der App (`www/i18n.js`) erzeugt und liegen dort in `docs/`. Änderungen bitte dort vornehmen und den Inhalt von `docs/` hierher kopieren.
